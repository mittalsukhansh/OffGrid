# Upstream attribution and provenance

OffGrid builds on the Android project originally published at
<https://github.com/vikramaditya19/OffGrid> by GitHub user **vikramaditya19**.
The original Git history also records contributions under **v1kk**. Those author
records are retained without rewriting them.

The inherited application baseline is commit
[`ea860f670d9be1a74c6d77756797e1caefd858be`](https://github.com/vikramaditya19/OffGrid/commit/ea860f670d9be1a74c6d77756797e1caefd858be),
including the earlier commits in its ancestry. Subsequent development in
<https://github.com/mittalsukhansh/OffGrid> includes contributions committed as
**mittalsukhansh**. The Git history is the detailed record of individual changes;
repository ownership is not a claim of sole authorship or copyright ownership.

At the 16 November 2026 check, neither the inherited tree/history examined nor the
upstream repository metadata supplied a repository license. No permission to
relicense inherited code has been confirmed. Attribution alone does not resolve
that permission gap. See [LICENSE](LICENSE) and
[UPSTREAM_PERMISSION.md](UPSTREAM_PERMISSION.md).

The GitHub-owned account name used in the Android application ID identifies this
repository's distribution namespace. It does not change the attribution or
ownership of upstream work.

Third-party libraries and tools retain their respective authorship and licensing.
The dependency inventory starts in `gradle/libs.versions.toml` and the Gradle build
files. This notice is not a complete dependency license inventory or legal review.

MIT-style license: https://www.bouncycastle.org/licence.html .
This dependency license does not grant rights to inherited OffGrid source.
